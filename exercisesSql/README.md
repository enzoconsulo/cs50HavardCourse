# exercisesSql 



This directory contains SQL labs and problem-set exercises from Harvard’s CS50 course. The two main exercises covered here are **Lab 7: Songs** (writing SQL queries against `songs.db`) and **PSet 7: Movies** (writing SQL queries against `movies.db`). 

---

## What you'll find here

Each exercise typically includes:
- One `.sql` files (e.g., `1.sql`, `2.sql`, …) where i write the required SQL query.
- A sample SQLite database file (e.g., `songs.db`, `movies.db`) used to run and test queries.
- A `README.md` (per exercise) explaining the task and how to run it .

Common files:
- `songs.db` — dataset for Lab 7 (Songs).
- `movies.db` — dataset used by Problem Set 7 (Movies).

---

## Exercises 

- [**songs/**](https://github.com/enzoconsulo/cs50HavardCourse/tree/main/exercisesSql/songs) — Write SQL queries (files `1.sql` → `8.sql`) to extract information from `songs.db` (e.g., list song names, order by tempo, compute averages, filter by artist or attributes). https://cs50.harvard.edu/x/2021/labs/7/

- [**movies/**](https://github.com/enzoconsulo/cs50HavardCourse/tree/main/exercisesSql/movies) — Solve the Movies problem set: a sequence of numbered `.sql` files (commonly `1.sql` → `13.sql`) querying `movies.db` and related tables (`people`, `stars`, `directors`, `ratings`) for titles, people, and relationships. https://cs50.harvard.edu/x/2021/psets/7/movies/
