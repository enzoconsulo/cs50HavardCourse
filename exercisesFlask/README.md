# exercisesFlask

This directory contains small Flask exercises from coursework and labs. Each subfolder holds a compact Flask project that demonstrates core backend concepts such as routing, templating (Jinja2), forms, and simple data persistence.

## Exercises

- [**birthdays/**](https://github.com/enzoconsulo/cs50HavardCourse/tree/main/exercisesFlask/birthdays) — A small Flask app that lets users add and list birthdays via a simple form and stores entries in a local SQLite database.  

- [**finance/**](https://github.com/enzoconsulo/cs50HavardCourse/tree/main/exercisesFlask/finance) — A CS50-style Flask application that simulates a simple stock trading system: user registration/login, fetching stock quotes, buying/selling shares, viewing portfolio and transaction history.
