# exercises HTML,CSS,JS

This directory contains front-end exercises in HTML, CSS, and JavaScript completed as part of coursework and labs. Each subfolder holds a small static project that demonstrates essential front-end concepts (page structure, styling, and basic client-side interactivity).



## Exercises

- [**homepage/**](https://github.com/enzoconsulo/cs50HavardCourse/tree/main/exercisesHTML%2CCSS%2CJS/homepage) — A small personal homepage (inspired by CS50 Pset 8). A static page containing a profile image, a welcome message, and a secondary biography page. Useful for practicing HTML structure, including images, and basic CSS styling.

- [**trivia/**](https://github.com/enzoconsulo/cs50HavardCourse/tree/main/exercisesHTML%2CCSS%2CJS/trivia) — A mini trivia quiz (inspired by CS50 Lab 8). A client-side quiz implemented with JavaScript in `index.html`, accompanied by a stylesheet. Useful for practicing DOM manipulation, simple quiz logic, and CSS layout.
